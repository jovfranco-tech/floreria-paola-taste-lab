# Security Policy

## Scope

Florería Paola Taste Lab is a static front-end design experiment. It does not include accounts, payments, a database, an order backend, or customer-data storage.

Reports are welcome for source-code, dependency, deployment, link-handling, privacy, or asset-loading issues.

## Reporting

Do not publish credentials, customer information, private business information, exploit details, or sensitive reproduction data in a public issue.

Use GitHub's private **Report a vulnerability** flow when available. Otherwise, open a minimal public issue requesting a private reporting channel and omit sensitive details.

A useful report includes:

- affected route or component;
- affected commit or deployment;
- realistic impact;
- minimal reproduction steps;
- suggested remediation, when known.

## Testing boundaries

Do not test WhatsApp accounts, phone numbers, third-party image services, Vercel infrastructure, or any system you do not own or have explicit permission to assess.
